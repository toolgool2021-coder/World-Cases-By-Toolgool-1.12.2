🇬🇧 ABOUT THE PROJECT

Welcome to TL Cases.

This is my own Minecraft mini-game based on the Cases mod for Minecraft 1.12.2.

The project contains a custom Minecraft world and 50 different Cases, each with its own items, rewards and configuration.

Everything in this project was created and configured by me.

💰 Get rewards.
🎁 Try your luck.
⛏️ Play in Minecraft 1.12.2.»

🛠️ INSTALLATION

1. Download the project

Download or clone this repository.

After downloading, extract the repository if it is provided as a ZIP archive.

Inside the repository you will find the required files, including the Cases configuration files and the Minecraft world.

---

2. Install Minecraft Forge

Install Minecraft Forge for Minecraft 1.12.2.

«⚠️ The exact Forge version will be added later.»

---

3. Install the Cases mod

Take the Cases mod from the repository and place it into your Minecraft Forge "mods" folder.

Example:

.minecraft/
└── mods/
    └── cases-0.6.3.jar

Start Minecraft using the Forge profile.

Wait until Minecraft reaches the main menu.

After that, close Minecraft completely.

---

4. Create the Cases configuration folder

Start Minecraft with the Cases mod installed.

The mod will automatically create its configuration directory.

The required folder will be:

.minecraft/
└── config/
    └── cases/

If the "cases" folder appears, the mod has been installed correctly.

Now close Minecraft again.

---

5. Install the Cases JSON files

Go back to the repository you downloaded.

Find the Cases configuration folder:

Cases/

Inside it you will find the Case configuration files:

1.json
2.json
3.json
...
50.json

Select all JSON files from 1 to 50.

Copy them into:

.minecraft/
└── config/
    └── cases/
        ├── 1.json
        ├── 2.json
        ├── 3.json
        ├── ...
        └── 50.json

These files contain the configuration of all 50 Cases.

---

6. Install the Minecraft world

Find the world included in the repository.

Move the world folder into your Minecraft saves directory:

.minecraft/
└── saves/
    └── TL Cases/

The exact world folder name may be different depending on the version of the project.

---

7. Launch the game

Start Minecraft 1.12.2 with Forge.

Open the installed world.

Everything should now be ready.

🎲 PLAY TL CASES

Open Cases, receive rewards and test your luck.

Have fun!

🛠️ УСТАНОВКА

1. Скачайте проект

Скачайте или клонируйте этот репозиторий.

Если репозиторий скачан в формате ZIP, распакуйте архив.

Внутри находятся необходимые файлы проекта, конфигурации кейсов и игровой мир.

---

2. Установите Minecraft Forge

Установите Minecraft Forge для Minecraft 1.12.2.

«⚠️ Точная версия Forge будет добавлена позже.»

---

3. Установите мод Cases

Найдите файл мода Cases в репозитории.

Перенесите его в папку "mods" вашего Minecraft Forge.

Например:

.minecraft/
└── mods/
    └── cases-0.6.3.jar

Запустите Minecraft через профиль Forge.

Дождитесь загрузки до главного меню.

После этого полностью закройте Minecraft.

---

4. Создайте папку Cases

Запустите Minecraft с установленным модом Cases.

Мод автоматически создаст необходимые конфигурационные файлы.

Нужная папка находится здесь:

.minecraft/
└── config/
    └── cases/

Если папка "cases" появилась, значит мод установился правильно.

После этого снова закройте Minecraft.

---

5. Установите JSON-файлы кейсов

Вернитесь в распакованный репозиторий.

Найдите папку:

Cases/

Внутри находятся конфигурации всех кейсов:

1.json
2.json
3.json
...
50.json

Скопируйте все JSON-файлы от 1 до 50.

Перенесите их сюда:

.minecraft/
└── config/
    └── cases/
        ├── 1.json
        ├── 2.json
        ├── 3.json
        ├── ...
        └── 50.json

После этого мод получит конфигурацию всех 50 кейсов.

---

6. Установите игровой мир

Найдите папку с миром в скачанном репозитории.

Перенесите её в папку сохранений Minecraft:

.minecraft/
└── saves/
    └── TL Cases/

Название папки мира может отличаться в зависимости от версии проекта.

---

7. Запустите игру

Запустите Minecraft 1.12.2 через Forge.

Выберите установленный мир.

После этого всё должно быть готово к игре.

🎲 ИГРАЙТЕ В TL CASES
